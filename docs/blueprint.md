# **App Name**: Skin Revolution

## Core Features:

- Personalized Skin Diagnostic Tool: AI tool analyzes user input (lifestyle, diet, concerns) to recommend optimal routines from the protocol.
- Recipe Database: Allows the user to visualize and filter available skincare recipes from the Protocol Anti-Industria method.
- Shopping List Generator: Generates a shopping list for the user based on their skin diagnostic results and preferred recipes, optimizing for the 47 monthly budget.
- Routine Scheduler: Enables the user to schedule the daily and weekly application of each recipe, optimizing for the time of day and duration.
- Cost Tracker: Tool for the user to track the expenses on ingredients used in the Protocol recipes, in order to not go over budget.
- Progress Tracking: Enable the user to upload before/after photos to compare them and assess if their chosen skincare routine is working well.

## Style Guidelines:

- Primary color: Soft rose (#F0948D), evoking the natural glow of healthy skin.
- Background color: Off-white (#F2EFE9), provides a clean, unobtrusive backdrop that emphasizes clarity and hygiene.
- Accent color: Dusty lavender (#C4A5C2), lends a sense of understated elegance and modernity.
- Body and headline font: 'Alegreya', a humanist serif, suitable for headlines or body text, giving an elegant, intellectual, contemporary feel
- Use minimalistic line icons representing ingredients, routines, and skin types.
- A clean, grid-based layout with ample white space for readability and ease of navigation.
- Subtle transitions and animations to guide the user through the app and provide visual feedback.
